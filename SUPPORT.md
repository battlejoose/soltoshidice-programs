# Support and privacy requests

Use the [public source repository](https://github.com/battlejoose/soltoshidice-programs) for project information.

- General questions and bug reports: [open an issue](https://github.com/battlejoose/soltoshidice-programs/issues). Include only information you are comfortable making public.
- Private privacy/account-data requests and security reports: [start a private report](https://github.com/battlejoose/soltoshidice-programs/security/advisories/new). GitHub requires an account. The form is labelled “Report a vulnerability”; identify a privacy request clearly in the title when applicable.
- To request access, correction, export or deletion of off-chain account data, describe the request and provide only the public wallet address needed to locate it. Ownership may need verification; never send private keys, seed phrases or credentials.

We review requests under applicable law and explain lawful retention exceptions. Blockchain records are public and permanent; neither clearing local app data nor a privacy request deletes chain records or closes existing positions. See [Privacy](https://soltoshidice.wtf/privacy) and [Terms](https://soltoshidice.wtf/terms).

Do not post personal information or undisclosed vulnerabilities in public issues. No response-time or bounty guarantee is offered.
