# Verification-tool permissions

Humans and AI-assisted reviewers may inspect and run these tools for independent, read-only verification, and report their findings without a required conclusion. Local audit clones, reproducible builds and isolated test changes are allowed under the root [LICENSE](../LICENSE).

The [AI policy](../AI_POLICY.md) restricts training and unauthorized product reuse; it does not prohibit source inspection or running the verification kit. Keep [the source-use explanation](../SOURCE_USE.md) with copies. Private app/backend access is not granted by these public tools.

This separate notice does not change files listed in source-manifest.json, the existing downloadable kit, or archived receipts. Compare the exact file hashes and observe each check's coverage limits.
